# Milestone R1 Analysis: Interactive Stance Visualizations

## 1. Overview
This report provides a concrete implementation strategy for **Milestone R1: Interactive Stance Visualizations** in the Presek platform. The goal of this milestone is to extract the `narrative_diversity` and `perspectives` properties from the cluster payload on the detail page and render them using custom visual elements (distribution bars, stance gradients, glassmorphism, and HSL palettes).

## 2. Payload Inspection & Data Retrieval

### Target File

### How Payload is Fetched and Assigned
In the Astro frontmatter of `[slug].astro` (lines 88-101), the cluster page fetches data from the backend:

   It is accessed inside `[slug].astro` as:
   ```typescript

   ```

### Schema Contracts
From backend investigations in `nlp/local_analyst.py` (line 67-71) and `routes/news.py`, the payload shapes are defined as:

1. **`narrative_diversity`** (JSONB schema generated by `PluralismResponse`):
   ```json
   {
     "score": 85,
     "verdict": "Visok pluralizam sa raznovrsnim izvorima...",
     "bias_detected": false
   }
   ```
   - `score`: integer from `0` to `100` mapping to the narrative's internal pluralism score.
   - `verdict`: string detailing the explanation of the diversity score (translated based on requested lang).
   - `bias_detected`: boolean flag indicating if significant bias/echo chamber tendencies were found.

2. **`perspectives`** (Array of `ClusterSummary` objects):
   ```json
   [
     {
       "angle": "Pro-vladin stav",
       "content": "Naglašava stabilnost i ekonomske uspehe..."
     },
     {
       "angle": "Kritika opozicije",
       "content": "Ukazuje na netransparentnost i nedostatke zakona..."
     }
   ]
   ```
   - Each element contains `angle` (the stance/perspective title) and `content` (supporting text).

## 3. Recommended UI/UX & CSS Architecture

We will implement the visuals using a glassmorphic look with HSL styling for smooth responsive scaling and high-fidelity dark-mode support.

### Custom CSS Variables
Add the following layout and color variables under `/home/emiloffingen/presek/web/src/styles/cluster-page.css` or in a scoped `<style>` block:

```css
:root {
  /* HSL Hue definitions for dynamic dynamic coloring */
  --stance-low-hue: 15;        /* Warm amber/red for low-diversity */
  --stance-high-hue: 145;      /* Cool green/teal for high-diversity */
  --stance-neutral-hue: 200;   /* Trust-worthy blue */

  /* Glassmorphism Presets */
  --stance-glass-bg: hsla(0, 0%, 100%, 0.45);
  --stance-glass-border: hsla(0, 0%, 100%, 0.25);
  --stance-glass-shadow: 0 8px 32px 0 rgba(196, 92, 38, 0.08);
  
  /* Stance Spectrum Track Gradients */
  --stance-grad-left: hsl(var(--stance-low-hue), 85%, 45%);
  --stance-grad-right: hsl(var(--stance-high-hue), 75%, 40%);
}

.dark {
  --stance-glass-bg: hsla(220, 15%, 8%, 0.55);
  --stance-glass-border: hsla(220, 10%, 20%, 0.35);
  --stance-glass-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
}
```

### Pure CSS Dynamic Color Calculation
For the narrative diversity score visual indicator, we can compute the metric's HSL representation dynamically on the element using inline styles. If we pass the score as an custom property (e.g. `--stance-score: 85`), the following CSS dynamically resolves the color spectrum from 0 (red) to 100 (green):

```css
.stance-meter-indicator {
  /* Interpolate hue between low-hue (15) and high-hue (145) */
  --dynamic-hue: calc(
    var(--stance-low-hue) + 
    (var(--stance-high-hue) - var(--stance-low-hue)) * 
    (var(--stance-score) / 100)
  );
  background-color: hsl(var(--dynamic-hue), 80%, 45%);
  left: calc(var(--stance-score) * 1%);
}
```

## 4. Implementation Strategy

### Component Design: `StanceVisuals.astro`
We propose adding a new widget or modifying the existing `CredibilityAnalysis.astro` to render the narrative diversity score and perspectives:

#### Astro Template
```astro
---
import { renderSynthesisHtml } from '../../utils/renderSynthesisHtml';
import { useTranslations } from '../../i18n/utils';

interface Props {
  diversity?: {
    score?: number;
    verdict?: string;
    bias_detected?: boolean;
  };
  perspectives: Array<{ angle: string; content: string }>;
  lang: 'sr' | 'mk';
}

const { diversity, perspectives = [], lang } = Astro.props;
const t = useTranslations(lang);
const score = diversity?.score ?? 50;
const verdict = diversity?.verdict || '';
const hasBias = diversity?.bias_detected || false;
---

<div class="stance-widget-container">
  <!-- 1. Narrative Diversity Meter -->
  {diversity && (
    <div class="narrative-diversity-card" style={`--stance-score: ${score}`}>
      <div class="card-header">
        <h4>{t('cluster.credibility.signal_discourse')}</h4>
        <span class="score-badge">{score}%</span>
      </div>
      
      <div class="stance-bar-track">
        <div class="stance-bar-gradient"></div>
        <div class="stance-meter-indicator"></div>
      </div>
      
      <p class="verdict-copy" set:html={renderSynthesisHtml(verdict)}></p>
      
      {hasBias && (
        <div class="bias-alert">
          <span class="alert-icon">⚠️</span>
          <p>{t('cluster.bias_alert') || 'Detektovana pristrasnost u pokrivenosti.'}</p>
        </div>
      )}
    </div>
  )}

  <!-- 2. Perspectives Spectrum -->
  {perspectives.length > 0 && (
    <div class="perspectives-spectrum-container">
      <h4>{t('cluster.factcheck.diversity')}</h4>
      <div class="perspectives-gradient-spectrum">
        {perspectives.map((p, idx) => {
          // Space cards along the spectrum
          const positionPercent = (idx / (perspectives.length - 1)) * 100;
          return (
            <div class="perspective-stance-card" style={`--position: ${positionPercent}%`}>
              <div class="perspective-badge" style={`background: color-mix(in srgb, var(--stance-grad-left) ${100 - positionPercent}%, var(--stance-grad-right))`}>
                {p.angle}
              </div>
              <p class="perspective-content" set:html={renderSynthesisHtml(p.content)}></p>
            </div>
          );
        })}
      </div>
    </div>
  )}
</div>
```
