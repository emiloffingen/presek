Join the shared "presek" cross-agent memory. The Shield runs a token-protected HTTP relay at http://100.77.135.12:8790/mcp ; you install a tiny stdio MCP client that forwards to it. No DB credentials needed. Run each step and report output.

STEP 1 — get the client (install curl if missing):
apt-get install -y curl >/dev/null 2>&1
mkdir -p /root/presek/mcp
curl -fsSL https://raw.githubusercontent.com/emiloffingen/presek/feat/fulltext-mk-transparency/mcp/shared_memory_client_http.py -o /root/presek/mcp/shared_memory_client_http.py
head -1 /root/presek/mcp/shared_memory_client_http.py && wc -l /root/presek/mcp/shared_memory_client_http.py
# Must print "#!/usr/bin/env python3" and a line count > 200.

STEP 2 — back up and show the opencode config:
mkdir -p /root/.config/opencode
cp /root/.config/opencode/opencode.json /root/.config/opencode/opencode.json.bak-$(date +%Y%m%d-%H%M%S) 2>/dev/null
cat /root/.config/opencode/opencode.json 2>/dev/null || echo "NO CONFIG YET"

STEP 3 — create/merge /root/.config/opencode/opencode.json so it contains this (keep any existing keys, add "memory" under "mcp"):
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "memory": {
      "type": "local",
      "command": ["python3", "/root/presek/mcp/shared_memory_client_http.py"],
      "enabled": true,
      "environment": {
        "SHARED_MEMORY_RELAY_URL": "http://100.77.135.12:8790/mcp",
        "SHARED_MEMORY_TOKEN": "COUXBasLNAHlqn_5O35HWuBdX1LbljNw1AZq_op67bQ",
        "PRESEK_AGENT_ID": "tablet"
      }
    }
  }
}
python3 -c "import json;json.load(open('/root/.config/opencode/opencode.json'));print('VALID JSON')"

STEP 4 — smoke-test the relay from the tablet:
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18"}}' '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"memory_stats","arguments":{"namespace":"presek"}}}' | SHARED_MEMORY_RELAY_URL=http://100.77.135.12:8790/mcp SHARED_MEMORY_TOKEN=COUXBasLNAHlqn_5O35HWuBdX1LbljNw1AZq_op67bQ PRESEK_AGENT_ID=tablet python3 /root/presek/mcp/shared_memory_client_http.py
# Expected: second line contains "namespace": "presek".

STEP 5 — restart opencode so the MCP loads.

STEP 6 — after restart, call the "memory" MCP tool memory_write with namespace=presek, kind=note, title="tablet online", body="tablet joined via relay".

Report the output of steps 1, 4 and 6. If raw.githubusercontent.com fails to resolve, or python3 is missing, stop and report the exact error.
